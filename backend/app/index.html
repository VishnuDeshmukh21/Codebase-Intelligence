Connect your repositories directly to your AI IDE.

This server indexes any Git repository or local folder into deterministic AST call graphs, symbol hierarchies, and vector embeddings. Your coding assistants (Cursor, Claude Desktop, Cline, Windsurf) connect over standard Model Context Protocol (MCP) to query blast radius, dependencies, and code architecture on demand using their host LLM.
